================================================================================
        PANDUAN LENGKAP PENGATURAN PAYMENT GATEWAY MIDTRANS
             (Sistem Pencari Jurnal Skripsi & Tesis)
================================================================================

Aplikasi ini telah siap terhubung 100% dengan Midtrans Payment Gateway.
Saat ini sistem berjalan dalam [MODE PLACEHOLDER (DEMO)], sehingga Anda bisa
menguji alur pembayaran lunas instan kapan saja tanpa terhambat.

Ketika Anda siap menghubungkan akun Midtrans resmi, ikuti 3 langkah mudah berikut:

--------------------------------------------------------------------------------
LANGKAH 1: DAFTAR AKUN MIDTRANS (GRATIS)
--------------------------------------------------------------------------------
1. Buka situs resmi: https://dashboard.midtrans.com
2. Klik tombol "Register" / "Daftar".
3. Isi nama, email bisnis/pribadi, nomor HP, dan password.
4. Verifikasi email Anda.
5. Anda akan langsung mendapatkan akses ke Dashboard Midtrans Sandbox (Gratis).

--------------------------------------------------------------------------------
LANGKAH 2: SALIN SERVER KEY & CLIENT KEY
--------------------------------------------------------------------------------
1. Masuk ke Dashboard Midtrans (https://dashboard.midtrans.com).
2. Pastikan tombol di kiri atas berada pada mode: "SANDBOX" (untuk uji coba)
   atau "PRODUCTION" (jika sudah aktif live).
3. Di bilah menu sebelah kiri, klik:
   [Settings] -> [Access Keys]
4. Anda akan melihat:
   - Merchant ID (contoh: G123456789)
   - Client Key  (contoh: SB-Mid-client-xxxxxxxxxxxx)
   - Server Key  (contoh: SB-Mid-server-xxxxxxxxxxxx)
5. Salin (Copy) kedua kunci tersebut.

--------------------------------------------------------------------------------

LANGKAH 4: SETTING URL NOTIFIKASI WEBHOOK (OPSIONAL - UNTUK SERVER LIVE)
--------------------------------------------------------------------------------
Jika aplikasi Anda sudah di-deploy ke server online / hosting berdomain:
1. Di Dashboard Midtrans -> [Settings] -> [Configuration].
2. Masukkan Payment Notification URL:
   https://domain-anda.com/api/payment/notification
3. Klik [Save Changes].
(Untuk localhost / offline di komputer lokal, sistem menggunakan verifikasi langsung).
